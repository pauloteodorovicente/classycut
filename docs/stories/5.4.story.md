## User Story

Como criador de conteudo usando o ClassyCut,
Quero gerar automaticamente um resumo textual do conteudo do meu video
a partir da transcricao,
Para poder usar na descricao do YouTube, legenda do Instagram, ou email de divulgacao.

---

## Contexto

Apos transcrever um video, o criador tem o texto completo mas ainda precisa
escrever um resumo manualmente. O ClassyCut pode gerar um resumo automatico
usando extracao (selecionar as frases mais representativas do texto)
sem precisar de API externa — algoritmo local de summarization por TF-IDF
ou simplesmente selecao das primeiras N sentencas de cada capitulo.

A implementacao MVP usa o metodo mais simples: selecionar as primeiras N sentencas
da transcricao completa, o que ja e muito util para descricoes rapidas.

## Notas de Implementacao

```python
# summarize.py
import re
from collections import Counter

def summarize_transcript(
    segments: list[dict],  # [{start_ms, end_ms, text}, ...]
    max_sentences: int = 5,
) -> str:
    """
    Extrai as sentencas mais representativas usando frequencia de palavras (TF).
    Retorna string com as sentencas selecionadas.
    """
    full_text = " ".join(seg["text"] for seg in segments)

    # Dividir em sentencas
    sentences = re.split(r'(?<=[.!?])\s+', full_text.strip())
    sentences = [s.strip() for s in sentences if len(s.split()) >= 4]

    if len(sentences) <= max_sentences:
        return " ".join(sentences)

    # TF: contar palavras (stopwords simples removidas)
    stopwords = {"o", "a", "os", "as", "de", "do", "da", "em", "e", "que", "um", "uma",
                 "para", "com", "se", "por", "mais", "como", "mas", "nao", "ao", "nas"}
    word_freq = Counter()
    for sent in sentences:
        for word in sent.lower().split():
            word = re.sub(r'[^\w]', '', word)
            if word and word not in stopwords:
                word_freq[word] += 1

    # Pontuar sentencas
    def score(sent: str) -> float:
        words = [re.sub(r'[^\w]', '', w.lower()) for w in sent.split()]
        return sum(word_freq.get(w, 0) for w in words if w) / max(len(words), 1)

    ranked = sorted(sentences, key=score, reverse=True)[:max_sentences]
    # Restaurar ordem original
    ordered = [s for s in sentences if s in ranked]
    return " ".join(ordered)
```
