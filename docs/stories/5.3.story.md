## User Story

Como criador de conteudo usando o ClassyCut,
Quero que o ClassyCut identifique automaticamente os capitulos do meu video
a partir da transcricao,
Para poder navegar rapidamente entre topicos e gerar a descricao do video para o YouTube.

---

## Contexto

Videos longos (tutoriais, podcasts, aulas) se beneficiam muito de capitulos.
Hoje o criador precisa assistir ao video inteiro e anotar manualmente os timestamps.

O ClassyCut ja tem a transcricao segmentada com timestamps (faster-whisper).
A partir dela, podemos usar heuristicas de mudanca de topico (pausas longas,
palavras-chave como "agora", "entao", "proximo") para identificar pontos de
divisao e gerar titulos sucintos.

## Notas de Implementacao

```python
# chapters.py
def generate_chapters(
    segments: list[dict],   # [{start_ms, end_ms, text}, ...]
    min_duration_s: float = 60.0,
) -> list[dict]:
    """
    Retorna lista de capitulos: [{start_ms, title}, ...]
    Algoritmo:
    1. Comecar com capitulo no inicio (t=0)
    2. Para cada segmento, verificar se ha pausa > 2s antes dele
       E se a duracao desde o ultimo capitulo >= min_duration_s
    3. Se sim, iniciar novo capitulo com o texto deste segmento como titulo
    4. Titulo = primeiras 6 palavras do segmento, capitalizado
    """
    chapters = [{"start_ms": 0, "title": "Introducao"}]
    last_chapter_start = 0

    for i, seg in enumerate(segments):
        if i == 0:
            continue
        gap_ms = seg["start_ms"] - segments[i-1]["end_ms"]
        duration_since_chapter = (seg["start_ms"] - last_chapter_start) / 1000

        if gap_ms > 2000 and duration_since_chapter >= min_duration_s:
            title = " ".join(seg["text"].split()[:6]).strip(".,:;").title()
            chapters.append({"start_ms": seg["start_ms"], "title": title or "Capitulo"})
            last_chapter_start = seg["start_ms"]

    return chapters
```

**Formato YouTube:**
```
00:00 Introducao
01:23 Configurando o ambiente
05:47 Primeiros passos
```
