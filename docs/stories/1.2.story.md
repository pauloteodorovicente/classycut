## User Story

Como desenvolvedor (ou usuario tecnico) que encontrou o ClassyCut,
Quero um README claro e completo na raiz do projeto,
Para entender o que e o app, como instalar, e como rodar sem precisar ler o codigo.

---

## Contexto

O projeto nao possui README. O unico arquivo de documentacao e o `CLAUDE.md` interno,
que e voltado para o assistente de IA, nao para humanos.

Um README e a primeira coisa que qualquer pessoa ve ao abrir o repositorio. Sem ele,
o projeto parece abandonado ou inacabado.
