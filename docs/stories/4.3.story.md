# Story 4.3 — Compartilhamento de projeto via link publico

**Epic:** 4 — Expansao de Features
**Story ID:** 4.3
**Status:** Done
**Priority:** Low
**Estimate:** M (1 dia)
**Agent:** @dev
**Depends on:** Story 2.1 (autenticacao JWT estabelecida)

---

## User Story

Como criador de conteudo usando o ClassyCut,
Quero compartilhar um projeto com um colaborador ou cliente via link publico,
Para que ele possa visualizar os arquivos de midia e os cortes definidos
sem precisar criar uma conta no ClassyCut.

---

## Contexto

Atualmente todos os projetos sao privados e exigem login para acesso.
Nao ha forma de mostrar o trabalho para um cliente ou colaborador
sem compartilhar as credenciais da conta.

Esta story implementa um sistema de links de compartilhamento somente-leitura:
o dono do projeto gera um token unico, qualquer pessoa com o link pode
visualizar (mas nao editar) o projeto.

## Notas de Implementacao

```python
# Model
class Project(Base):
    share_token: Mapped[str | None] = mapped_column(String, unique=True, nullable=True)

# Endpoint publico (sem CurrentUser)
@router.get("/share/{token}", response_model=ProjectShareResponse)
def get_shared_project(token: str, db: Session = Depends(get_db)):
    project = db.query(Project).filter(Project.share_token == token).first()
    if not project:
        raise HTTPException(status_code=404, detail="Link invalido ou expirado")
    return project
```
