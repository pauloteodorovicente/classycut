# Story 2.1 — Autenticacao de usuarios (cadastro e login)

**Epic:** 2 — Web Ready
**Story ID:** 2.1
**Status:** Done
**Priority:** High (blocker para deploy web)
**Estimate:** L (2-3 dias)
**Agent:** @dev
**Depends on:** Story 1.1

---

## User Story

Como usuario do ClassyCut na web,
Quero me cadastrar com email e senha e fazer login,
Para que meus projetos e videos sejam privados e acessiveis apenas por mim.

---

## Contexto

O ClassyCut atualmente nao tem nenhuma autenticacao. Qualquer pessoa que
acesse a URL do servidor consegue ver e editar todos os projetos de todos os usuarios.

Isso e aceitavel para uso local/pessoal, mas e um bloqueio absoluto para deploy web.

Esta story implementa autenticacao JWT simples no backend e o fluxo de login/cadastro
no frontend. Apos esta story, todos os endpoints da API exigirao um token valido.

---

## Acceptance Criteria

### Backend
- [x] AC-1: Endpoint `POST /api/v1/auth/register` cria novo usuario (email + senha)
- [x] AC-2: Senhas armazenadas com hash bcrypt (nunca em texto plano)
- [x] AC-3: Endpoint `POST /api/v1/auth/login` retorna JWT access token
- [x] AC-4: Token JWT tem expiracao de 7 dias (configuravel via env var)
- [x] AC-5: Todos os endpoints existentes exigem token valido no header `Authorization: Bearer {token}`
- [x] AC-6: Projetos e midia sao filtrados por `user_id` — usuarios nao veem dados de outros
- [x] AC-7: Endpoint `GET /api/v1/auth/me` retorna dados do usuario logado
- [x] AC-8: Modelo `User` adicionado ao banco com migracao Alembic

### Frontend
- [x] AC-9: Pagina `/login` com formulario de email e senha
- [x] AC-10: Pagina `/register` com formulario de cadastro
- [x] AC-11: Token armazenado no `localStorage` apos login
- [x] AC-12: Axios interceptor adiciona token automaticamente em todas as requisicoes
- [x] AC-13: Redirect automatico para `/login` quando token expirado ou ausente
- [x] AC-14: Botao de logout limpa token e redireciona para `/login`
- [x] AC-15: Rota `/` (HomePage) protegida — requer login

```python

from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"])
```

## Seguranca

- Nunca logar senhas ou tokens
- Usar HTTPS em producao (Vercel/Railway ja fornecem)
- Secret key deve ter 32+ bytes aleatorios
- Nao expor stack trace de erros de autenticacao
