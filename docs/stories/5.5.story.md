**Epic:** 5 — IA Avancada e Produtividade
**Story ID:** 5.5
**Status:** Draft
**Priority:** High
**Estimate:** L (2-3 dias)
**Agent:** @dev
**Depends on:** Story 3.2 (transcricao com faster-whisper estabelecida)

---

## User Story

Como editor de video usando o ClassyCut,
Quero clicar em qualquer palavra da transcricao para pular para aquele momento no video,
e poder selecionar trechos de texto para marcar para remover ou manter,
Para fazer cortes de precisao guiados pelo conteudo falado — sem precisar
procurar manualmente na timeline.

---

## Contexto

Editores profissionais de podcast e entrevista editam pelo texto, nao pela timeline.
Ferramentas como Descript popularizaram este paradigma.

O ClassyCut ja tem a transcricao segmentada com timestamps por palavra (faster-whisper
com `word_timestamps=True`). O que falta e a interface interativa para:
1. **Click-to-seek:** clicar em qualquer palavra vai para aquele ponto no player
2. **Selecao para corte:** selecionar um trecho de texto marca aquele intervalo
   de tempo para remover (ou manter)
3. **Exportar cortes textuais:** aplicar os cortes marcados gerando novo arquivo

---

```typescript
// Highlight sincronizado — derivado de currentTime, nao state separado
// Para evitar re-renders excessivos, usar CSS class toggle via ref direto no DOM
// ou React.memo agressivo por palavra

// Selecao de intervalo
// mousedown -> registrar palavra inicial
// mouseup -> registrar palavra final
// -> calcular [start_ms, end_ms] do intervalo
// -> mostrar popover "Remover | Manter"

// Palavras com marcacao:
// vermelho = marcado para remover
// verde = marcado para manter
// cinza = sem marcacao (padrao)
```

**Performance:** A transcricao pode ter centenas de palavras. Usar `React.memo` por palavra
e evitar re-renders desnecessarios. O highlight de palavra atual deve ser implementado
via `ref` e manipulacao direta de className para nao re-renderizar tudo a cada frame.

**Integracao com cutStore:** Os trechos marcados via transcricao alimentam o mesmo
`segments` array do cutStore, permitindo que o botao "Aplicar cortes" existente
funcione sem modificacao.
