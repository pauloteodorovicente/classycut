## User Story

Como criador de conteudo usando o ClassyCut,
Quero comprimir meu video para um tamanho-alvo (ex: abaixo de 50 MB)
sem precisar saber nada sobre codecs ou bitrate,
Para poder subir o arquivo em plataformas com limite de tamanho como WhatsApp e email.

---

## Contexto

Videos modernos podem ter varios GBs de tamanho, tornando-os inviabilizados
para compartilhamento direto. O usuario nao sabe ajustar bitrate ou CRF manualmente.

O ClassyCut pode calcular automaticamente o bitrate necessario para atingir
um tamanho-alvo usando a formula de two-pass encoding ou ajuste de CRF do FFmpeg.

O backend ja tem FFmpeg disponivel e ja cria jobs assincronos.

## Notas de Implementacao

```python
# Calculo de bitrate para two-pass
def _calculate_target_bitrate(duration_s: float, target_mb: float, audio_kbps: int = 128) -> int:
    total_kbps = (target_mb * 8192) / duration_s
    video_kbps = int(total_kbps - audio_kbps)
    return max(video_kbps, 200)  # minimo de 200 kbps

# Two-pass encoding
# Pass 1: ffmpeg -y -i input -c:v libx264 -b:v {bitrate}k -pass 1 -an -f null /dev/null
# Pass 2: ffmpeg -y -i input -c:v libx264 -b:v {bitrate}k -pass 2 -c:a aac -b:a 128k output
```

**Progresso via stderr:** FFmpeg emite `frame=... fps=... time=...` no stderr.
Parsear `time=HH:MM:SS.ss` e dividir pela duracao total para obter percentual.
