## User Story

Como criador de conteudo usando o ClassyCut,
Quero exportar meu video com as legendas ja gravadas dentro da imagem,
Para postar no Instagram ou TikTok onde as legendas aparecem automaticamente
sem depender de arquivos externos de legenda.

---

## Contexto

Atualmente o ClassyCut gera arquivos de legenda (SRT/VTT) que ficam separados do video.
Para a maioria das plataformas sociais, isso nao funciona — o video precisa ter as legendas
"queimadas" (burn-in) diretamente nos frames.

O FFmpeg ja suporta isso com o filtro `subtitles=arquivo.srt`.

Esta feature depende apenas de uma transcricao previa feita pelo usuario.
Nao exige nenhuma dependencia nova — apenas FFmpeg que ja esta disponivel.

## Notas de Implementacao

```python
# FFmpeg burn-in de legendas
vf = f"subtitles='{srt_path}':force_style='FontSize={font_size},Alignment={alignment}'"

cmd = [
    settings.ffmpeg_path, "-y",
    "-i", str(video_path),
    "-vf", vf,
    "-c:v", "libx264", "-crf", "18", "-preset", "fast",
    "-c:a", "copy",
    str(output_path),
]
```

**Nota sobre Windows:** O caminho do SRT no filtro `subtitles=` em Windows requer
escapar as barras invertidas. Usar caminho com forward slashes ou temp dir em /tmp.

**Tamanhos de fonte recomendados:**
- Pequeno: 16px (para videos 1080p)
- Medio: 22px (padrao)
- Grande: 28px (para mobile/vertical)
