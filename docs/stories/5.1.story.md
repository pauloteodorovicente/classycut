## User Story

Como criador de conteudo usando o ClassyCut,
Quero aumentar a resolucao do meu video (2x ou 4x),
Para melhorar a qualidade visual de gravacoes antigas ou com baixa resolucao.

---

## Contexto

Videos gravados em baixa resolucao (720p ou menos) podem ser upscalados para 1080p ou 4K
antes de publicar. O ClassyCut suporta dois metodos:

1. **FFmpeg lanczos** — sempre disponivel, rapido, qualidade boa
2. **Real-ESRGAN** — binario externo opcional, qualidade superior (IA), mais lento

O backend ja tem FFmpeg disponivel e ja cria jobs assincronos.
Real-ESRGAN e opcional e detectado dinamicamente pela config.

import shutil, subprocess
from app.config import settings

def is_realesrgan_available() -> bool:
    return shutil.which(settings.realesrgan_path) is not None

def upscale_ffmpeg(input_path, output_path, factor: int) -> None:
    cmd = [
        settings.ffmpeg_path, "-y", "-i", str(input_path),
        "-vf", f"scale=iw*{factor}:ih*{factor}:flags=lanczos",
        "-c:v", "libx264", "-crf", "18",
        "-c:a", "copy",
        str(output_path),
    ]
    res = subprocess.run(cmd, capture_output=True, text=True, timeout=7200)
    if res.returncode != 0:
        raise RuntimeError(f"FFmpeg upscale failed: {res.stderr}")
