## User Story

Como criador de conteudo usando o ClassyCut,
Quero identificar automaticamente os momentos de maior energia e impacto do meu video,
Para encontrar rapidamente os melhores trechos sem assistir ao video inteiro.

---

## Contexto

Creators de conteudo frequentemente precisam encontrar o "melhor momento" de uma gravacao
longa — o climax de uma partida de jogo, o pico de uma reacao, o trecho mais energico de
um podcast. Isso e feito manualmente hoje, o que e demorado.

O ClassyCut pode analisar o RMS (Root Mean Square) do audio do video para detectar
picos de energia — momentos onde o audio e mais alto e intenso — e apresenta-los
como "highlights" navegaveis.

O backend ja tem FFmpeg disponivel para extrair audio e ja cria jobs assincronos.

## Notas de Implementacao

```python
# highlights.py — analise de RMS por janela
import subprocess, re

def detect_highlights(
    file_path: str,
    sensitivity: float = 0.5,    # 0.0 = detecta tudo, 1.0 = apenas picos extremos
    min_duration: float = 2.0,   # segundos
    window_size: float = 0.5,    # segundos por janela de analise
) -> list[dict]:
    """
    Retorna lista de {'start_ms', 'end_ms', 'energy'} ordenada por energia desc.
    """
    cmd = [
        "ffmpeg", "-i", file_path,
        "-af", f"asetnsamples=n={int(44100*window_size)},astats=metadata=1:reset=1,"
               "ametadata=print:key=lavfi.astats.RMS_level:file=-",
        "-vn", "-f", "null", "-"
    ]
    # Parsear saida: "lavfi.astats.RMS_level=-24.5" com timestamps
    # Calcular limiar: percentil baseado na sensibilidade
    # Agrupar janelas consecutivas acima do limiar em highlights
```

**Calculo do limiar:**
- Coletar todos os valores de RMS em dBFS
- Converter dBFS para linear (energia): `10^(rms_db/20)`
- Limiar = percentil `(1 - sensitivity) * 100`
- Ex: sensitivity=0.7 → limiar = percentil 30 (top 30% de energia)

**Formato do resultado no job:**
```json
{
  "highlights": [
    {"start_ms": 12500, "end_ms": 17800, "energy": 0.85},
    {"start_ms": 45200, "end_ms": 51000, "energy": 0.72}
  ]
}
```
