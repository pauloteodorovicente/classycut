**Epic:** 4 — Expansao de Features
**Story ID:** 4.2
**Status:** Draft
**Priority:** Medium
**Estimate:** L (2-3 dias)
**Agent:** @dev
**Depends on:** Stories 3.1, 3.2 (ferramentas de edicao estabelecidas)

## User Story

Como editor de video usando o ClassyCut,
Quero poder desfazer e refazer qualquer acao de edicao com Ctrl+Z / Ctrl+Y,
independente de qual ferramenta estou usando,
Para ter a mesma seguranca de trabalho que tenho em qualquer editor profissional.

---

## Contexto

Atualmente o undo/redo (Ctrl+Z / Ctrl+Y, ate 100 operacoes) existe APENAS na
ferramenta de Corte Manual. As demais ferramentas nao tem essa capacidade:

| Ferramenta | Undo atual |
|-----------|-----------|
| Corte Manual | Sim (100 niveis, story 3.1) |
| Auto-Corte (Silencio) | Nao |
| Zoom | Nao |
| Configuracoes de projeto | Nao |

Esta story implementa um sistema de undo/redo centralizado que funciona para
todas as operacoes de edicao, usando o padrao Command Pattern.

## Notas de Implementacao

```typescript
// historyStore.ts
interface EditCommand {
  description: string
  execute: () => void
  undo: () => void
}

interface HistoryStore {
  past: EditCommand[]
  future: EditCommand[]
  execute: (cmd: EditCommand) => void
  undo: () => void
  redo: () => void
  clear: () => void
}
```

O `execute()` roda o comando imediatamente, empilha no historico e limpa o future.
O `undo()` chama `cmd.undo()` e move o comando para future.
O `redo()` chama `cmd.execute()` e move de volta para past.
