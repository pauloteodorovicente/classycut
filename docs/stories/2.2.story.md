## User Story

Como dono do produto,
Quero o ClassyCut acessivel pela internet com uma URL publica,
Para usar a ferramenta de qualquer lugar sem precisar do meu computador ligado.

---

## Contexto

O ClassyCut precisa de duas implantacoes separadas:
1. **Frontend (React)** → Vercel (gratuito, perfeito para SPA estatica)
2. **Backend (FastAPI + FFmpeg)** → Railway (suporta Docker, FFmpeg disponivel)

O backend precisa de Docker porque o FFmpeg deve estar instalado no container.
O Railway suporta deploy via Docker Compose ou Dockerfile diretamente.

**ATENCAO:** O Vercel NAO pode hospedar o backend porque:
- FFmpeg nao funciona em funcoes serverless
- Operacoes de longa duracao (> 10s) sao abortadas
- Nao ha sistema de arquivos persistente

## Decisao de Storage

**Opcao A — Volume Railway (mais simples, mais rapido)**
- Railway oferece volumes persistentes
- Os arquivos ficam no disco do container
- Limite: depende do plano Railway

**Opcao B — Cloudflare R2 ou AWS S3 (mais robusto)**
- Arquivos na nuvem, separados do servidor
- Escala ilimitada
- Requer implementacao de upload direto para o storage
- Recomendado para producao com muitos usuarios

**Recomendacao inicial:** Opcao A (volume Railway) para comecar rapidamente.
Migrar para Opcao B quando o uso crescer.
