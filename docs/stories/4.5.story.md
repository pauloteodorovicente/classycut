## User Story

Como criador de conteudo usando o ClassyCut,
Quero exportar meu video ja no formato ideal para uma rede social especifica
(Instagram Reels, TikTok, YouTube Shorts, WhatsApp),
Para nao precisar saber as especificacoes tecnicas de cada plataforma.

---

## Contexto

Cada plataforma tem suas proprias restricoes de resolucao, aspect ratio,
duracao maxima e tamanho de arquivo:

| Plataforma | Resolucao | Aspect Ratio | Tamanho max |
|-----------|-----------|--------------|-------------|
| Instagram Reels | 1080x1920 | 9:16 | 650 MB |
| TikTok | 1080x1920 | 9:16 | 500 MB |
| YouTube Shorts | 1080x1920 | 9:16 | 256 MB |
| WhatsApp | 640x1136 | 9:16 | 16 MB |
| YouTube (padrao) | 1920x1080 | 16:9 | sem limite pratico |

O ClassyCut pode aplicar crop + resize + compressao automaticamente
ao exportar para uma plataforma alvo.

# presets.py

    "instagram_reels": {"width": 1080, "height": 1920, "max_mb": 650},
    "tiktok":          {"width": 1080, "height": 1920, "max_mb": 500},
    "youtube_shorts":  {"width": 1080, "height": 1920, "max_mb": 256},
    "whatsapp":        {"width": 640,  "height": 1136, "max_mb": 16},
    "youtube":         {"width": 1920, "height": 1080, "max_mb": None},

# ou  crop=iw:iw*16/9,scale=1920:1080  (para 16:9 a partir de vertical)
