## User Story

Como desenvolvedor implantando o ClassyCut em qualquer ambiente,
Quero que a configuracao do banco de dados nao tenha caminhos fixos do meu computador pessoal,
Para que o app funcione corretamente em qualquer maquina sem ajuste manual.

---

## Contexto

O arquivo `backend/app/config.py` contem um caminho hardcoded:

```python
database_url: str = "sqlite:///C:/Users/HP/video-editor/storage/classycut.db"
```

Este caminho pertence ao computador original de desenvolvimento (usuario HP).
Em qualquer outro ambiente (Docker, servidor, outro computador), o banco de dados
sera criado no lugar errado ou nao sera encontrado.

O campo `storage_dir` ja usa `Path(__file__)` corretamente — o `database_url` precisa
seguir o mesmo padrao.

## Notas de Implementacao

A solucao mais simples e usar `@computed_field` ou `model_validator` do Pydantic para
derivar o `database_url` a partir do `storage_dir` ja calculado:

```python
# Opcao A: property computada
@property
def computed_database_url(self) -> str:
    return f"sqlite:///{self.storage_dir / 'classycut.db'}"

# Opcao B: valor padrao relativo (sem @)
database_url: str = ""  # calculado no model_validator
```

Ou mais simples ainda — apenas corrigir o default para um caminho relativo:
```python
database_url: str = "sqlite:///./storage/classycut.db"
```
